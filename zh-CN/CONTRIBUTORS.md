## 贡献类型

我们认可所有类型的贡献：

- 💻 **代码**：编写代码、修复缺陷、实现新功能
- 📝 **文档**：撰写文档、教程、示例
- 🧪 **测试**：编写测试、提高测试覆盖率
- 🐛 **缺陷报告**：发现并报告缺陷
- 💡 **创意**：提出新功能或改进建议
- 🎨 **设计**：UI/UX 改进、图形设计、品牌设计
- 🎨 **示例**：制作教程和示例
- 💬 **社区**：解答问题、审阅 PR
- 🎓 **教育**：博客文章、视频教程、演讲、工作坊
- 🔧 **工具**：创建工具、脚本、集成
- 📦 **打包**：改进构建、发布、分发流程
- ⚠️ **安全**：报告安全漏洞
- 🏗️ **基础设施**：CI/CD、托管、基础设施
- 🚇 **维护**：维护、问题分类、项目管理

## 如何添加自己

### 自动认可

如果您提交过 commit，您会自动出现在 [GitHub 的贡献者图谱](https://github.com/semantica-agi/semantica/graphs/contributors) 中。

### 使用 All-Contributors Bot

在任何 issue 或 PR 下评论：

```
@all-contributors please add @username for code, docs, bug
```

**示例：**

```
@all-contributors please add @johndoe for code
@all-contributors please add @janedoe for docs, bug
@all-contributors please add @devuser for code, test, maintenance
```

### 手动添加

打开一个 PR，将您自己添加到本文件中：

```markdown
- [Your Name](https://github.com/yourusername) - 💻 📝 🐛
```

## 贡献类型代码

使用 all-contributors bot 时，请使用以下代码：

- `code` - 代码贡献
- `doc` - 文档
- `test` - 测试
- `bug` - 缺陷报告
- `ideas` - 功能请求/创意
- `design` - 设计工作
- `example` - 示例/样例
- `question` - 回答问题
- `talk` - 演讲/展示
- `tool` - 工具/集成
- `packaging` - 打包/分发
- `security` - 安全报告
- `infra` - 基础设施
- `maintenance` - 维护

完整的列表请参阅 [all-contributors 规范](https://github.com/all-contributors/all-contributors#emoji-key)。
