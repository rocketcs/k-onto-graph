# Semantica

Use this skill when a request involves Semantica, knowledge graphs, context graphs, entities, relations, semantic extraction, reasoning, provenance, ontology, policy, ingestion, deduplication, decision intelligence, or graph visualization.

Choose the smallest workflow that satisfies the request. Inspect relevant module documentation or code only when the task needs it, and use the repository's existing interfaces and conventions. Prefer direct execution and clear deliverables; do not require a fixed sequence of planning, searching, delegation, or testing steps when the task does not benefit from them.

For graph work, preserve provenance and explainability when the product path supports them. For external data, respect credentials, privacy, and repository security constraints. Run focused validation appropriate to the change; broaden checks only when failures or risk justify it.

Common request shapes include:

- extract entities, relations, or events and summarize the resulting graph;
- analyze topology, paths, centrality, communities, or embeddings;
- create or inspect decisions, causal links, rationale, and provenance;
- define or validate ontology, SHACL, reasoning rules, or policies;
- ingest, normalize, deduplicate, enrich, or export graph data.
